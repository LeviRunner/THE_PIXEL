# Asset List: Coleta / Sobrevivência

**Contexto:** O personagem base possui `1.80m` de altura. Para o estilo isométrico do jogo, os itens interativos e de drop precisam ter proporções ligeiramente exageradas (mais espessos/gordinhos) para garantir uma boa leitura da silhueta de longe.

## 5. Novos Itens e Peças Faltantes (Expansão de Coleta e Sobrevivência)
*Equipamentos adicionais de caçador, lenhador, pescador e curtume.*

- [ ] **Serrote Traçador de Dois Lenhadores** (`1.4m compr x 0.2m larg com dois punhos`) - Lâmina dentada de aço para corte rápido de toras gigantes.
- [ ] **Kit Pederneira e Isqueiro de Pedra** (`0.15m bolso de couro com pedra e ferro`) - Acessório essencial para acender fogueiras sem magia.
- [ ] **Fardo de Peles Enroladas com Tiras** (`0.7m compr x 0.35m diâm`) - Rolo de peles tratadas amarrado com correias de couro para transporte.
- [ ] **Moldura de Madeira para Esticar Couro** (`1.2m alt x 0.9m larg x 0.08m prof`) - Cavalete quadrangular com cordas tensionando uma pele de animal.
- [ ] **Cesto de Vime de Coletor com Bagas / Frutas** (`0.4m x 0.3m x 0.25m com alça`) - Cesto trançado transbordando cogumelos, amoras e raízes.
- [ ] **Estojo de Iscas e Anzóis de Madeira** (`0.35m x 0.25m x 0.12m aberto com divisórias`) - Caixa de pesca com iscas coloridas e chumbadas.
- [ ] **Vara com Peixes Defumados Pendurados** (`0.8m compr com 4 peixes secos`) - Prop rústico com peixes amarrados pela cauda.
- [ ] **Cantil de Pele / Odre de Água** (`0.3m alt x 0.18m larg com tira de ombro`) - Recipiente flexível de couro com bocal de chifre.
- [ ] **Agulha de Osso e Carretel de Tendão** (`0.2m compr`) - Ferramenta rústica para costurar peles, barracas e bolsas.
