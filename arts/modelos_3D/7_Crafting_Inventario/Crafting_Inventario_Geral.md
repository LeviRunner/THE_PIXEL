# Asset List: Crafting Geral, Ladinagem e Inventário

**Contexto:** O personagem base possui `1.80m` de altura. Para o estilo isométrico do jogo, os itens interativos e de drop precisam ter proporções ligeiramente exageradas (mais espessos/gordinhos) para garantir uma boa leitura da silhueta de longe.

## 1. Componentes de Artesanato Base
- [ ] **Tecido e Pano Dobrado** (`0.4m x 0.3m`) - Rolo ou trouxa de tecido cru, linho ou seda vermelha.
- [ ] **Novelo de Corda** (`0.3m diâm`) - Corda grossa enrolada com extremidade solta.
- [ ] **Cerâmica / Vidro** (`0.3m alt`):
    - [ ] Vaso de barro quebrável
    - [ ] Ânfora bojuda
    - [ ] Placa translúcida de vidro
- [ ] **Carapaça de Inseto / Chifre Polido** (`0.4m compr`) - Drop orgânico de criaturas para reforço de armaduras.

## 2. Inventário e Saques (Loot)
- [ ] **Mochila do Jogador** (`0.5m x 0.4m`) - Bolsa de couro bojuda de aventureiro com correias, adaptada para fixar nas costas do `ModularCharacter`.
- [ ] **Cinto de Batalha com Pochetes** (`0.4m larg`) - Acessório modular de cintura.
- [ ] **Saco de Loot Genérico** (`0.4m alt`) - Saquinho de pano amarrado com cordinha para drops agrupados de monstros no chão.
- [ ] **Tesouros e Riquezas:**
    - [ ] Moeda Imperial Única (`0.15m diâm` - proporcionalmente grande para leitura clara)
    - [ ] Pilha de Moedas de Ouro (`0.3m x 0.3m base`)
    - [ ] Saco de Moedas Rechonchudo (`0.4m alt`)
- [ ] **Chaves de Masmorra** (`0.3m compr` - silhueta bem marcada):
    - [ ] Chave de Bronze
    - [ ] Chave de Prata
    - [ ] Chave de Ouro
    - [ ] Chave Gigante de Ferro
    - [ ] Chave Espectral Translúcida

## 3. Baús e Contêineres
- [ ] **Baú de Madeira Pequeno** (`0.8m x 0.5m x 0.5m`) - Baú rústico comum de ripas com tampa arredondada.
- [ ] **Baú Trancado de Ferro** (`1.0m x 0.6m x 0.6m`) - Baú de masmorra reforçado com chapas e fechadura pesada.
- [ ] **Baú do Acampamento / Banco do Jogador** (`1.5m x 1.0m x 0.9m`) - Baú suntuoso com forro de veludo e ferragens douradas para a base/fortaleza.

## 4. Estruturas de Ladinagem e Base
- [ ] **Barracas de Mercado** (`2.0m x 2.0m base x 2.5m alt`):
    - [ ] Barraca de Alimentos / Pães
    - [ ] Barraca de Tecidos / Seda
    - [ ] Barraca de Ourives / Prata
    - [ ] Barraca de Joias e Gemas
- [ ] **Bancada de Artesão / Carpinteiro** (`1.5m x 0.8m mesa`) - Mesa rústica com tesouras, retalhos de couro esticados, plaina e rolos de linha.
- [ ] **Tenda de Acampamento Simples** (`2.0m x 2.0m`) - Tenda piramidal de lona com estacas de madeira.


## 5. Novos Itens e Peças Faltantes (Expansão de Artesanato e Inventário)
*Ferramentas de alfaiataria, marcenaria, ladinagem e bens de comércio valiosos.*
- [ ] **Tesoura Grande de Alfaiate de Ferro** (`0.35m compr total com anéis laranjas`) - Tesoura pesada para corte limpo de rolos de seda e couro.
- [ ] **Plaina Manual de Madeira do Carpinteiro** (`0.4m compr x 0.15m larg com espiral de madeira`) - Bloco com lâmina de aço para desbaste de tábuas.
- [ ] **Brunidor Cônico de Couro (Slicker)** (`0.25m compr x 0.06m diâm com ranhuras`) - Haste de madeira dura para polir bordas de coldres e cintos.
- [ ] **Carretel de Madeira com Linha Grossa e Agulha** (`0.2m alt x 0.15m diâm carretel`) - Fio de linho cru enrolado com agulha espetada.
- [ ] **Estojo de Gazúas de Ladino com Ferramentas** (`0.2m x 0.15m bolsa aberta`) - Bolsa com 3 michas de aço para arrombamento de baús.
- [ ] **Lingote Maciço de Ouro Puro (Bullion de Tesouro)** (`0.3m compr x 0.15m larg x 0.1m alt`) - Barra de alto valor com cunho do Império.
- [ ] **Lupa de Ourives / Joalheiro com Aro de Latão** (`0.25m compr com lente 0.12m diâm`) - Lupa de mão para avaliar gemas e engastes.
- [ ] **Cofre Portátil de Ferro com Fechadura e Chave** (`0.4m x 0.3m x 0.25m alt`) - Caixa forte reforçada para transporte de joias.
- [ ] **Rolo de Tecido de Seda Colorida Estampada** (`0.6m compr x 0.2m diâm enrolado`) - Tecido nobre de importação para vestimentas de luxo.
- [ ] **Placa de Sinalização de Madeira Suspensa por Correntes** (`0.6m larg x 0.45m alt`) - Tábua rústica para pendurar na fachada de lojas e tendas.

## 6. Assets de Cenário e Ambientação (Diorama / Feira e Oficina de Artesão)
*Módulos urbanos e comerciais para compor mercados, oficinas de alfaiate e postos avançados.*
- [ ] **Barraca Comercial com Toldo Listrado Azul e Branco** (`2.2m larg x 1.8m prof x 2.4m alt`) - Estrutura de madeira com lona e mesas expositoras.
- [ ] **Bancada de Marcenaria com Painel de Ferramentas** (`1.8m compr x 0.8m prof x 1.8m alt`) - Mesa com serrote, plaina, machadinha e aparas de madeira no chão.
- [ ] **Cavalete Expositor de Roupas e Tecidos** (`1.2m larg x 1.4m alt x 0.4m prof`) - Arara de madeira com dobras de tecidos coloridos pendurados.
- [ ] **Poste de Iluminação de Feira com Duas Lanternas** (`2.8m alt x 0.8m envergadura`) - Viga entalhada com braços de ferro e lamparinas a óleo.
- [ ] **Piso de Pavimento de Paralelepípedos com Degraus** (`2.0m x 2.0m x 0.25m módulo`) - Plataforma de pedras assentadas com escadaria frontal.
- [ ] **Pilha de Caixotes com Cordas e Garrafas** (`0.9m x 0.9m x 1.0m conjunto`) - Três caixas empilhadas com novelos e garrafas de vinho/azeite.
- [ ] **Balcão de Câmbio com Balança de Moedas** (`1.4m compr x 0.6m larg x 0.9m alt`) - Mesa com gaveta com tranca e pilhas de moedas de ouro.
- [ ] **Cerca de Madeira Rústica de Limite de Feira** (`2.0m compr x 1.0m alt`) - Mourões entalhados com duas travessas para delimitar calçadas.
