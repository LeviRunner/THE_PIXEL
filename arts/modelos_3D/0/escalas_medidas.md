# Guia de Escalas e Medidas para Modelagem 3D

**Referência Base:** Personagem Humanoide com **1.80m de altura** (180cm).
> **Nota de Design (Isométrico/Top-Down):** Em jogos com essa perspectiva, é comum exagerar levemente a espessura e o tamanho de itens pequenos (como moedas, frascos e ferramentas) para garantir a "leitura visual" na tela. As medidas abaixo consideram proporções realistas, mas já adaptadas para terem volume suficiente em *low poly*.

---

## 1. Mineração
- [ ] **Pedra bruta / Veio de minério:** 0.8m x 0.8m x 0.6m (Alt) - *Aproximadamente na altura da cintura do personagem*
- [ ] **Picareta:** 0.9m de cabo x 0.4m de lâmina (cabeça)
- [ ] **Minério bruto / Carvão (Item Drop):** 0.25m x 0.25m x 0.25m
- [ ] **Fragmento de rocha:** 0.15m x 0.15m x 0.1m

## 2. Forjamento (Smithing)
- [ ] **Bigorna pequena:** 0.8m (Comp) x 0.3m (Larg) x 0.7m (Alt) - *Abaixo da cintura para facilitar a batida*
- [ ] **Forno/Forja:** 1.2m (Larg) x 1.2m (Prof) x 1.5m (Alt)
- [ ] **Martelo de forja:** 0.4m de cabo x 0.15m de cabeça
- [ ] **Barra de metal (Lingote):** 0.2m x 0.1m x 0.05m
- [ ] **Placa de metal:** 0.4m x 0.4m x 0.02m

## 3. Coleta / Sobrevivência
- [ ] **Galho seco (recurso):** 0.6m de comprimento x 0.05m de espessura
- [ ] **Madeira bruta (Tora):** 1.0m de comprimento x 0.3m de diâmetro
- [ ] **Couro cru (esticado no chão/drop):** 0.8m x 0.6m x 0.02m
- [ ] **Osso:** 0.4m de comprimento

## 4. Alquimia
- [ ] **Bancada de alquimia:** 1.2m (Larg) x 0.6m (Prof) x 0.9m (Alt) - *Altura exata para manipulação com as mãos*
- [ ] **Caldeirão pequeno:** 0.6m de diâmetro x 0.5m de altura (geralmente apoiado no chão ou em fogo baixo)
- [ ] **Frasco vazio/cheio (Vial):** 0.15m (Alt) x 0.08m (Diâmetro) - *Levemente exagerado para ser visto de longe*
- [ ] **Ervas/raízes (Buquês):** 0.2m a 0.3m de altura

## 5. Encantamento
- [ ] **Mesa de encantamento (Pedestal + Livro):** 1.0m (Larg) x 1.0m (Prof) x 0.9m (Alt do tampo)
- [ ] **Livro de encantamento (Aberto):** 0.5m x 0.35m x 0.05m
- [ ] **Runa (Pedra):** 0.1m x 0.1m x 0.05m
- [ ] **Cristal arcano:** 0.2m x 0.2m x 0.4m
- [ ] **Pergaminho:** 0.3m de comprimento (enrolado)

## 6. Livros de Habilidade & Árvore de Habilidades
- [ ] **Nó da árvore (Skill node - Pedestal):** 0.5m de diâmetro x 0.8m de altura
- [ ] **Ícone 3D de skill (Flutuando sobre o nó):** ~0.3m x 0.3m x 0.3m
- [ ] **Conector de árvore (Linha/Viga):** Varia em comprimento, mas ~0.1m a 0.15m de espessura para conectar visualmente os pedestais
- [ ] **Marco de ramo (Totem maior):** 0.8m de diâmetro x 1.2m de altura

## 7. Crafting Geral / Inventário
- [ ] **Baú pequeno:** 0.6m (Larg) x 0.4m (Prof) x 0.4m (Alt)
- [ ] **Saco de itens (Loot):** 0.4m (Diâmetro da base) x 0.5m (Alt)
- [ ] **Tecido (Pano dobrado):** 0.3m x 0.3m x 0.1m
- [ ] **Corda (Novelo):** 0.3m de diâmetro x 0.1m de altura
- [ ] **Moedas (Pilha):** 0.15m de diâmetro na base da pilha

## 8. Equipamentos Básicos
- [ ] **Espada curta:** 0.7m de comprimento total (Aproximadamente do quadril até o joelho do personagem)
- [ ] **Adaga:** 0.3m de comprimento total
- [ ] **Machado de mão:** 0.5m de comprimento
- [ ] **Lança curta:** 1.5m de comprimento (pouco menor que o personagem)
- [ ] **Escudo redondo:** 0.6m de diâmetro (cobre do ombro à cintura)
- [ ] **Capuz/Colete:** Ocupa um volume aproximado de 0.5m de largura x 0.6m de altura (encaixe no torso do char de 1.80m)

## 9. Ambiente Mínimo
- [ ] **Mesa rústica:** 1.5m (Larg) x 0.8m (Prof) x 0.9m (Alt)
- [ ] **Pedestal para livro:** 0.4m x 0.4m (Base) x 1.1m (Alt) - *O topo fica em um ângulo confortável para leitura*
- [ ] **Suporte de ferramentas (Parede):** 1.0m (Larg) x 0.2m (Alt) x 0.05m (Prof), montado a ~1.4m do chão
