# Asset List: Forjamento (Smithing)

**Contexto:** O personagem base possui `1.80m` de altura. Para o estilo isométrico do jogo, os itens interativos e de drop precisam ter proporções ligeiramente exageradas (mais espessos/gordinhos) para garantir uma boa leitura da silhueta de longe.

## 1. Estações de Trabalho
*Modelos de forja, bigorna e aquecimento.*

- [X] **Forno / Forja Principal** (`1.8m alt, 1.2m larg, 1.0m prof`):
    - [x] Estrutura base de tijolos de pedra refratária com fornalha frontal em arco aberto exibindo brasas/metal fundido.
    - [x] Chaminé no topo guiando a fumaça para cima.
    - [ ] Mecanismo de sopro na lateral direita (roda/fole) conectado por haste curva até um **pedal frontal** para o ferreiro pisar enquanto trabalha na fornalha.
- [X] **Grande Fornalha** (`2.5m alt, 1.5m larg, 1.5m prof`) - Upgrade nível 45 ou drop de Anão Renegado; feita de ferro escuro, comporta múltiplas barras simultâneas. (removido das artes)
- [x] **Oficina de Carpinteiro / Bigorna Portátil** (`0.8m alt`) - Toco rústico de madeira com placa metálica no topo.
- [x] **Bigornas por Tiers:**
    - [x] **Bigorna Pequena** (`0.6m larg x 0.8m alt com base`) - Bigorna de ferro simples montada sobre toco de carvalho.
    - [x] **Bigorna Reforçada** (`0.9m larg x 0.9m alt`) - Base fundida reforçada com suportes laterais.
    - [X] **Bigorna Ancestral** (`1.2m larg x 1.0m alt`) - Drop do Chefe Capataz de Pedra; maciça, cravada com runas anãs emissivas que pulsam a cada batida.

## 2. Ferramentas
- [x] **Martelo de Forja** (`0.5m compr, 0.2m cabeça do martelo`) - Martelo curto de uma mão, cabeça em bloco de ferro espesso e cabo encapado.
- [x] **Martelo de Gárgula** (`0.6m compr`) - Ferramenta/arma de Exterminação com cabeça esculpida em pedra cinzenta.
- [x] **Pinças / Tenazes de Ferreiro** (`0.4m compr`) - Prop articulado para repousar sobre a bigorna ou fornalha.

## 4. Novos Itens e Peças Faltantes (Expansão de Forjamento)
*Itens, ferramentas e componentes intermediários adicionais para a progressão completa de metalurgia.*
- [ ] **Bandeja de Moldes de Lingote** (`0.5m x 0.3m x 0.08m`) - Molde de ferro fundido com cavidades para vazar metal líquido.
- [ ] **Balde / Tina de Têmpera** (`0.6m diâm x 0.8m alt`) - Barril de madeira com aros de ferro cheio d'água/óleo para resfriar peças quentes.
- [ ] **Rebolo de Amolar / Afiador de Pedal** (`0.8m larg x 0.5m prof x 1.0m alt`) - Roda circular de pedra abrasiva com pedal e correia para afiar lâminas.
- [ ] **Fole Manual Portátil** (`0.6m compr x 0.25m larg`) - Fole de couro com bico de ferro para avivar fogo de forjas menores.
- [ ] **Tenaz Curva de Mandíbula Larga** (`0.45m compr`) - Pinça especializada para segurar peças redondas e chapas grossas.
- [ ] **Pá de Carvão da Fornalha** (`0.8m compr x 0.2m larg pá`) - Pá de metal curta com cabo de madeira para alimentar a forja.
- [ ] **Almotolia de Óleo do Ferreiro** (`0.25m alt x 0.12m diâm`) - Frasco metálico com bico curvo para lubrificação e têmpera.
- [ ] **Barra Incandescente na Tenaz** (`0.5m compr`) - Prop especial emissivo (metal brilhando em brasa alaranjada/amarela).
- [ ] **Suporte com Avental de Couro** (`1.2m alt x 0.5m larg`) - Cavalete rústico segurando avental pesado de proteção.
- [x] **Balde de Carvão Mineral** (`0.3m diâm x 0.35m alt`) - Baldinho de ripas cheio de carvão para reposição rápida.
- [ ] **Torno de Bancada / Morsa** (`0.3m x 0.25m x 0.25m`) - Morsa de ferro forjado para prender peças durante o desbaste.
- [ ] **Escova de Aço para Escória** (`0.3m compr`) - Escova grossa com cerdas de arame para limpar casca de óxido do metal.

## 5. Assets de Cenário e Ambientação (Diorama / Oficina)
*Elementos modulares para montar a oficina do ferreiro completa no mundo do jogo.*
- [x] **Bancada de Trabalho do Ferreiro** (`1.6m compr x 0.7m prof x 0.9m alt`) - Mesa de madeira maciça com reforços de ferro e prateleira inferior.
- [ ] **Prateleira de Parede para Armas** (`1.5m larg x 0.3m prof x 1.0m alt`) - Suporte de tábuas na parede para exibir espadas, machados e lanças prontas.
- [x] **Suporte de Parede para Martelos** (`1.0m larg x 0.15m prof`) - Barra de ferro com ganchos para pendurar múltiplos martelos de forja.
- [x] **Chão Modular de Pedra Refratária** (`2.0m x 2.0m x 0.1m`) - Placa de piso de pedras polidas gastas com marcas de fuligem.
- [x] **Paredes da Oficina com Nichos** (`2.0m larg x 2.5m alt x 0.2m prof`) - Módulo de parede de pedra rústica com nichos para tochas/ferramentas.
- [x] **Duto de Ventilação Superior** (`0.4m diâm x 1.5m compr`) - Tubo de metal com abafador conectando a chaminé ao telhado.
- [ ] **Pilha de Sucata e Aparas de Metal** (`0.8m diâm x 0.3m alt`) - Monte de sobras irregulares de metal no chão da forja.
- [ ] **Tacho de Fundição Suspenso** (`0.4m diâm x 0.5m alt`) - Recipiente basculante de cerâmica/grafite para vazar metal fundido.
