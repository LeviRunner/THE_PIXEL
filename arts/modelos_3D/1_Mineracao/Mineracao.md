# Asset List: Mineração

**Contexto:** O personagem base possui `1.80m` de altura. Para o estilo isométrico do jogo, os itens interativos e de drop precisam ter proporções ligeiramente exageradas (mais espessos/gordinhos) para garantir uma boa leitura da silhueta de longe.

## 1. Nódulos (No Mundo)
*São os blocos que o jogador clica para minerar. Devem ter um visual robusto, brotando do chão.*

- [ ] **Veio de Minério Genérico (Malha Base)** (`1.0m x 1.0m x 0.8m`) - Base de pedra cinzenta incrustada com cristais/pedaços de metal.
    - [ ] Variação de Textura/Emissive: **Cobre** (Laranja)
    - [ ] Variação de Textura/Emissive: **Estanho** (Cinza fosco)
    - [ ] Variação de Textura/Emissive: **Ferro-Negro** (Preto profundo)
    - [ ] Variação de Textura/Emissive: **Prata** (Branco brilhante)
    - [ ] Variação de Textura/Emissive: **Ouro** (Amarelo cintilante)
    - [ ] Variação de Textura/Emissive: **Auralita** (Azul/Verde neon)
    - [ ] Variação de Textura/Emissive: **Vermécio** (Vermelho vivo escuro)
    - [ ] Variação de Textura/Emissive: **Minério Sombrio** (Roxo/Preto cintilante)
- [ ] **Pedreira de Argila/Granito** (`1.2m x 1.2m`) - Bloco liso e terroso (vermelho para argila, escuro para granito).
- [ ] **Veio de Carvão** (`0.8m x 0.8m x 0.6m`) - Pedra mais escura e porosa.
- [ ] **Veio de Gemas** (`1.0m x 1.0m x 0.9m`) - Base de pedra com pontas cristalinas pontiagudas saindo.

## 2. Drops / Inventário
*Os itens que caem no chão ou vão para a mochila.*

- [ ] **Minério Bruto** (`0.3m x 0.3m`) - Pedaço irregular de rocha (exagerado para clique no chão).
    - [ ] Variação de Cor: Cobre
    - [ ] Variação de Cor: Estanho
    - [ ] Variação de Cor: Ferro-Negro
    - [ ] Variação de Cor: Prata
    - [ ] Variação de Cor: Ouro
    - [ ] Variação de Cor: Auralita
    - [ ] Variação de Cor: Vermécio
    - [ ] Variação de Cor: Sombraço
- [ ] **Carvão** (`0.25m x 0.25m`) - Nódulo negro brilhante irregular.
- [ ] **Pedra-Essência / Pedras Rúnicas** (`0.2m`) - Pedras brutas com um símbolo entalhado que brilha levemente.
- [ ] **Fragmento de Rocha** (`0.2m`) - Lixo/drop comum (cascalho).
- [ ] **Gemas Brutas (Cristais Lapidados)** (`0.15m x 0.15m`):
    - [ ] Rubi (Vermelho)
    - [ ] Safira (Azul)
    - [ ] Quartzo / Diamante (Translúcido/Branco)
    - [ ] Esmeralda (Verde)

## 3. Ferramentas (Nas Mãos do Jogador)
- [ ] **Picareta Comum (Malha Base)** (`1.2m comprimento total, 0.5m envergadura da lâmina, 0.08m espessura do cabo`) - Ferramenta de duas mãos com lâmina espessa e visível.
    - [ ] Tier 1: Bronze
    - [ ] Tier 2: Ferro
    - [ ] Tier 3: Aço
    - [ ] Tier 4: Ouro
    - [ ] Tier 5: Vermécio
    - [ ] Tier 6: Sombraço
    - [ ] Tier 8: Auralita
- [ ] **Picareta do Capataz** (`1.3m compr`) - Drop único do Chefe 'Capataz de Pedra'. Feita puramente de Auralita com entalhes rúnicos que brilham no escuro.

## 4. Ambiente de Mina
- [ ] **Carrinho de Mina** (`1.2m x 0.8m x 0.7m`) - De madeira gasta com rodas de ferro.
- [ ] **Trilhos de Mina** (`2.0m x 0.8m` por segmento) - Madeira de dormente e linhas de ferro.
- [ ] **Lanterna de Mina** (`0.3m alt`) - Lanterna a óleo quadrada com alça de ferro.
- [ ] **Lanterna do Capataz** (`0.4m alt`) - Drop do chefe, lanterna elaborada com câmara de luz dupla para iluminar cavernas profundas.


## 5. Novos Itens e Peças Faltantes (Expansão de Mineração)
*Ferramentas adicionais, insumos de extração e subprodutos de mineração profunda.*
- [ ] **Marreta Pesada de Britador** (`0.9m compr total x 0.25m cabeça`) - Marreta de duas mãos com bloco chanfrado para estilhaçar pedras grandes.
- [ ] **Talhadeira / Cinzel de Aço** (`0.35m compr x 0.05m diâm`) - Ponteira chanfrada de ferro para extração precisa de gemas.
- [ ] **Feixe de Dinamite / Carga Alquímica** (`0.3m alt x 0.15m diâm`) - Cartuchos vermelhos amarrados com barbante e estopim curto para detonação de veios.
- [ ] **Capacete de Minerador com Vela/Lanterna** (`0.3m x 0.25m x 0.2m`) - Capacete de couro/ferro com suporte frontal de iluminação.
- [ ] **Bateia de Garimpo / Garimpador** (`0.4m diâm x 0.08m prof`) - Prato cônico estriado para peneirar pepitas nos rios.
- [ ] **Geodo Rachado de Ametista/Quartzo** (`0.35m x 0.3m x 0.2m`) - Rocha oca partida ao meio revelando cristais roxos no interior.
- [ ] **Caixa de Separação de Minérios** (`0.6m x 0.45m x 0.35m`) - Caixote de ripas com divisórias cheias de pepitas e cascalho.
- [ ] **Saco de Amostras Geológicas** (`0.3m alt x 0.2m diâm`) - Bolsa de lona amarrada com etiqueta de pergaminho pendurada.
- [ ] **Perfuratriz Manual a Vapor / Broca Rúnica** (`0.7m compr`) - Ferramenta gnômica compacta com manivela e broca espiralada.
- [ ] **Balde de Cascalho e Sedimento** (`0.35m alt x 0.3m diâm`) - Balde de madeira reforçado com alça de ferro.

## 6. Assets de Cenário e Ambientação (Diorama / Túnel da Mina)
*Módulos de mina, escoras e túneis para preenchimento de cavernas subterrâneas.*
- [ ] **Escora de Sustentação de Madeira (Portal de Mina)** (`2.2m alt x 1.8m larg x 0.25m prof`) - Vigas verticais e travessa superior de madeira bruta entalhada.
- [ ] **Escora Angular com Reforço** (`2.2m alt x 0.3m espessura`) - Pilar de canto de madeira com mãos-francesas inclinadas.
- [ ] **Pilha de Entulho e Cascalho Solto** (`1.2m diâm x 0.4m alt`) - Monte de pedregulhos e pó cinzento encostado nas paredes.
- [ ] **Segmento de Trilho Curvo** (`2.0m raio x 0.8m larg`) - Curva modular de dormentes para conexão de trilhos da mina.
- [ ] **Desvio de Trilhos com Alavanca** (`1.5m x 1.0m`) - Sistema mecânico com dormentes de ferro e haste com contrapeso.
- [ ] **Pilha de Vigas de Madeira Serradas** (`1.5m compr x 0.8m larg x 0.6m alt`) - Toras quadradas empilhadas para obras de contenção.
- [ ] **Boca de Túnel de Mina (Entrada de Galeria)** (`3.0m alt x 2.5m larg x 1.5m prof`) - Módulo de arco rochoso com escoras de madeira.
- [ ] **Plataforma Elevada de Madeira** (`2.0m x 2.0m x 1.2m alt`) - Tablado com rampa e escada para descarregar carrinhos.
