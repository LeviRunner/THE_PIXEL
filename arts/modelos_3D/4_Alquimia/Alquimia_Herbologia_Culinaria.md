# Asset List: Alquimia, Herbologia e Culinária

**Contexto:** O personagem base possui `1.80m` de altura. Para o estilo isométrico do jogo, os itens interativos e de drop precisam ter proporções ligeiramente exageradas (mais espessos/gordinhos) para garantir uma boa leitura da silhueta de longe.

## 1. Estações de Trabalho
- [ ] **Bancada de Alquimia** (`1.2m larg x 0.6m prof x 0.9m alt`) - Mesa de madeira com alambique de vidro, serpentinas, tubos de ensaio e almofariz com pilão de pedra no canto.
- [ ] **Caldeirão Pequeno / Grande** (`0.8m diâm x 0.6m alt`) - Panela esférica de ferro fundido com três pés sobre fogueira; malha circular interna para líquido borbulhante.
- [ ] **Fogão de Tijolos / Forno de Cozinha** (`1.0m x 1.0m x 0.9m`) - Estação avançada de Culinária com chapa e boca de fogo.
- [ ] **Fogueira de Acampamento** (`0.8m diâm`):
    - [ ] Modelo sem fogo (pedras e lenha empilhada)
    - [ ] Modelo com fogo aceso e espeto de assar carne
- [ ] **Braseiro de Grupo** (`1.0m alt`) - Pedestal metálico para buff de fogueira em área.

## 2. Recipientes e Poções
- [ ] **Frasco Vazio (Vial - Malha Base)** (`0.2m alt x 0.1m diâm`) - Frasco arredondado com gargalo e rolha de cortiça.
- [ ] **Poções (Variações de Cor e Brilho no Líquido):**
    - [ ] Tônico de Vigor (Verde claro / Amarelado)
    - [ ] Poção de Força (Vermelho vivo)
    - [ ] Antídoto (Branco / Azul muito claro)
    - [ ] Poção de Defesa (Cinza / Prateado)
    - [ ] Poção de Recurso (Amarelo escuro / Âmbar)
    - [ ] Veneno de Arma (Verde esmeralda tóxico)
    - [ ] Elixir Arcano / Pontaria (Azul elétrico / Laranja)
    - [ ] Poção de Coragem (Dourado reluzente)
- [ ] **Bolsa Abissal** (`0.4m x 0.3m`) - Saco de couro roxo escuro costurado com aura mágica sombria.

## 3. Ingredientes Místicos e Naturais
- [ ] **Buquês de Ervas** (`0.3m compr`):
    - [ ] Ervamarga
    - [ ] Folha-de-Guarda
    - [ ] Flor-de-Cinza (Botão cinzento)
    - [ ] Musgo-Lunar (Brilho azulado suave)
- [ ] **Raízes Medicinais** (`0.3m`) - Raiz-de-Ferro (raiz tuberosa preta e retorcida).
- [ ] **Pós e Misturas** (`0.15m`) - Pequeno monte de pó colorido sobre folha ou saquinho aberto.
- [ ] **Ingredientes Monstruosos (Drops):**
    - [ ] Rabo de Rato (`0.2m`)
    - [ ] Olho Vermelho de Aranha (`0.15m`)
    - [ ] Poça de Ectoplasma (`0.3m diâm` - gosma translúcida azulada)
    - [ ] Sangue de Sanguessuga (`0.15m` - frasco globular)
    - [ ] Cinzas Infernais (`0.2m` - pó incandescente laranja)
- [ ] **Drops Especiais de Chefe:**
    - [ ] Coração de Seiva (`0.4m diâm` - núcleo vegetal pulsante)
    - [ ] Semente da Clareira (`0.3m diâm` - semente com runas verdes brilhantes)
- [ ] **Cristal / Orbe de Mana Bruta** (`0.3m alt`) - Fragmento cristalino flutuante.

## 4. Alimentos Preparados
- [ ] **Alimentos Assados** (`0.3m a 0.5m`):
    - [ ] Pão de Campanha (Crocante redondo)
    - [ ] Torta de Batata
    - [ ] Torta de Maçã
    - [ ] Torta de Javali (Em travessa de barro)
- [ ] **Tigela de Ensopado / Caldo** (`0.3m diâm`) - Tigela de madeira com colher apoiada.
- [ ] **Caneca de Cerveja de Cevada** (`0.25m alt`) - Caneca grossa com espuma saindo da borda.
- [ ] **Banquete Imperial / do Caçador** (`1.0m x 0.6m`) - Toalha de banquete posta no chão com várias carnes, frutas e queijos para descanso coletivo.


## 5. Novos Itens e Peças Faltantes (Expansão de Alquimia e Culinária)
*Instrumentos de precisão laboratorial, destilação e preparo culinário.*
- [ ] **Balança de Dois Pratos com Pesos de Latão** (`0.45m larg x 0.45m alt`) - Balança de precisão para dosagem de pós rúnicos e sementes.
- [ ] **Retorta de Vidro com Bico Curvado** (`0.3m compr x 0.2m diâm`) - Recipiente de vidro soprado para destilação de essências puras.
- [ ] **Almofariz e Pilão de Pedra com Papa Verde** (`0.25m diâm x 0.2m alt`) - Tigela pesada com polpa de ervas maceradas no fundo.
- [ ] **Espiriteira a Álcool com Trempe de Ferro** (`0.3m alt x 0.22m diâm`) - Queimador de latão com chama viva para aquecer frascos.
- [ ] **Suporte de Tubos de Ensaio com Reagentes** (`0.35m compr x 0.1m larg x 0.2m alt`) - Base de madeira com 4 frascos cilíndricos coloridos.
- [ ] **Ramo de Ervas Aromáticas para Secagem** (`0.35m compr com laço de barbante`) - Buquê invertido com folhas secas para pendurar em vigas.
- [ ] **Moinho Manual de Especiarias / Moedor de Madeira** (`0.2m x 0.2m x 0.25m com manivela`) - Moedor com gaveta inferior para triturar pimenta e raízes.
- [ ] **Panela de Barro Refratário com Tampa** (`0.4m diâm x 0.3m alt com alças`) - Caçarola rústica para cozimento lento de caldos e ensopados.
- [ ] **Concha de Metal Grande do Cozinheiro** (`0.4m compr com gancho no cabo`) - Utensílio para servir poções e sopas do caldeirão.
- [ ] **Pergaminho de Fórmula Alquímica Estendido** (`0.4m compr x 0.25m larg`) - Folha com diagramas botânicos e receitas rúnicas.

## 6. Assets de Cenário e Ambientação (Diorama / Boticário)
*Módulos de laboratório, estantes de botica e cantos de preparo mágico.*
- [ ] **Estante Rústica de Parede com Poções** (`1.8m alt x 1.2m larg x 0.35m prof`) - Armário aberto com três prateleiras repletas de frascos iluminados.
- [ ] **Fogão Alquímico de Alvenaria com Grelha** (`1.0m x 1.0m x 0.85m alt`) - Base de tijolos com nicho para lenha e suporte de ferro para caldeirão.
- [ ] **Aparador de Livros / Atril de Fórmulas** (`1.1m alt x 0.6m larg x 0.5m prof`) - Pedestal inclinado com livro de receitas aberto sob luz de lamparina.
- [ ] **Condensador com Serpentina de Vidro Suspenso** (`0.8m alt x 0.3m diâm`) - Tubo em espiral conectado por suportes de bronze.
- [ ] **Piso de Lajes de Pedra Polida de Laboratório** (`2.0m x 2.0m x 0.1m`) - Módulo de lajotas cinzentas com manchas circulares de reagentes.
- [ ] **Viga Superior com Varal de Ervas Penduradas** (`2.0m compr x 0.2m espessura`) - Viga de madeira com ganchos segurando alho, lavanda e cogumelos.
- [ ] **Banqueta Alta do Boticário** (`0.6m alt x 0.35m diâm assento`) - Banco de madeira redondo de três pés.
- [ ] **Pote Grande de Cerâmica para Fermentação** (`0.6m alt x 0.45m diâm com rolha`) - Jarro bojudo para armazenar poções em repouso.
